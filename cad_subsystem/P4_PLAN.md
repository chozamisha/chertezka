# P4 — план системы контроля качества

## Цель

Инженерный контроль чертежа: данные → геометрия OCP → оформление листа.  
Не сводить к подсчёту DXF-сущностей. NOT_CHECKED ≠ PASS.

## Слои проверок

1. **inputs** — CastingSpec/provenance/TechGeomParams, единицы, допущения  
2. **geometry** — validate_derived, OCP intersection, объёмы, галтель, проекции  
3. **drawing** — виды/сечения/оси/базы/размеры/штриховка/ТТ/штамп  
4. **eskd** — только с известным основанием (ГОСТ / внутреннее правило)

## Статусы

`PASS` | `FAIL` | `WARNING` | `NOT_CHECKED`

`fully_verified` только если нет `FAIL` и нет `NOT_CHECKED`.
