# P3 — план (до реализации)

## Исходные данные

| Элемент | Есть в CastingSpec / calc | Не хватает для «полной» геометрии |
|---------|---------------------------|-----------------------------------|
| Лопатки | N=4, высота канала C_H_CH, радиальное пространство | **профиль по шаблону**, толщина, углы входа/выхода |
| Ст.1 / знаки | L_PRINT, H_CH, C_OUT, rim_wall | ширина знака по дуге (есть практика 50 мм на чертеже) |
| Ст.2 | C_BORE, H_PRINT2, схема A | — достаточно для цилиндра+знака |
| ЛС | F_PIT, F_SLAG, F_SPRUE, N_PIT | точная 3D-трасса в опоке (есть схема на плане) |
| Прибыль | D_RISER, D_NECK, H_RISER | радиус галтели (на legacy R≈8) |
| Холодильники | a=40 / a=30, дуга~90°, 2 шт. | точная дуговая длина в мм |

## Принцип

1. Реальные OCP-тела только из явных параметров (`TechGeomParams` + CastingSpec).
2. Лопатки P3 = **призматические радиальные пластины** (OCP Fuse) — не гидравлический профиль.
3. Недостающие поля → `MissingTechDataError`, без подстановки «на глаз» в silent-режиме; для колеса — явный engineer-пакет с provenance.
4. P1 calc не менять.
5. Тестировать каждый блок отдельно.

## Порядок реализации

1. TechGeomParams + worker primitives (box, annulus, blade, riser_neck_fillet, assembly)
2. Лопатки → тест section/HLR
3. Стержни + знаки → тест положения
4. ЛС из площадей P1 → тест связности
5. Прибыль+шейка+галтель, холодильники
6. Местное Б-Б через знак Ст.1
7. QA пересечений
8. Отчёт `P3_GEOMETRY_COMPLETENESS.md`
